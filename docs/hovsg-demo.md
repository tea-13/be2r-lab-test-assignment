# Визуальное демо HOV-SG: Replica room0

Для настоящей иерархии этажей/комнат/объектов теперь есть отдельный [HM3DSem graph demo](hovsg-graph-demo.md): `make hovsg-graph-demo`.

Демо показывает сохранённую **feature map HOV-SG**: геометрию комнаты, сегменты объектов и результаты текстового поиска. Это небольшой внешний GUI поверх исходных результатов. Построение карты выполняет штатный `application/semantic_segmentation.py`; загрузку embeddings и оценку запросов — штатные `load_feature_map` и `text_prompt(..., templates=True)` из `hovsg/utils/eval_utils.py`. Исходники submodule не меняются.

Для Replica авторский `application/create_graph.py` явно пропускает иерархический graph. Поэтому здесь не показываются искусственно придуманные этажи/комнаты и не используется `visualize_query_graph.py`, которому нужен другой формат данных. OpenAI API/ключ не требуется.

## Запуск и управление

Из корня workspace после подготовки карты:

```bash
make hovsg-demo
```

При старте загружается локальный OpenCLIP ViT-H, поэтому окно появляется не мгновенно. Нужны GPU и рабочий X11 DISPLAY. Все веса уже скачаны; для обычного просмотра интернет не нужен.

| Элемент окна | Действие |
|---|---|
| Text query + Search | Введите `sofa`, `pillow`, `lamp`, `chair`, `vase` или описание на английском |
| Top 5 | Нажмите строку, чтобы выбрать соответствующий сегмент; номер соответствует `objects/pcd_<id>.ply` |
| RGB | Исходные цвета карты, выбранный результат выделен оранжевым |
| Instances | Отдельный постоянный цвет каждого сегмента; это не semantic class labels |
| Similarity | Относительное сходство сегментов с последним запросом: синий — ниже, красный — выше |
| Selected object | Затемнённая RGB-карта, оранжевый выбранный сегмент и рамка |
| Hide ceiling | Убирает верхние 25 см облака из отображения, чтобы увидеть интерьер; файлы/признаки не меняются |
| Reset view | Возвращает общий ракурс комнаты |
| Save screenshot | Сохраняет изображение 3D-вида в `results/hovsg/screenshots/` |
| Quit / закрыть окно | Завершает демо |

Мышью: перетаскивание — вращение, колесо — масштаб, Ctrl+перетаскивание — сдвиг. Запрос также печатает top-5 ID/similarity в терминал. Similarity — cosine score, **не вероятность и не accuracy**. «Ваза у окна» не означает явную проверку пространственного отношения: поиск сравнивает текст с признаками сегментов.

## Подготовка карты

```bash
make hovsg-build-demo
```

Используются уже имеющиеся 2000 RGB-D кадров Replica room0 и исходные poses/intrinsics. `skip_frames=100` выбирает **20 кадров 0,100,…,1900** вдоль траектории. SAM `points_per_batch=8`, `points_per_side=12`; остальные параметры — штатные. Это короткое построение для демонстрации, не полный benchmark.

Каждый запуск создаёт `results/hovsg/demo-map-<date>-<pid>/raw/replica`. Только после успешного завершения относительный путь записывается в `data/cache/hovsg/demo-map.txt`; просмотрщик читает его. Если указателя ещё нет, он может открыть сохранённую трёхкадровую карту Этапа 3. Отсутствующие assets не скачиваются автоматически.

Чтобы открыть другой совместимый результат Replica с теми же ViT-H embeddings:

```bash
HOVSG_MAP_DIR="$PWD/results/hovsg/replica-20261009-015744-1071525/raw/replica" make hovsg-demo
```

Полные команды и overrides находятся в [build script](../scripts/hovsg-build-demo.sh), [launch script](../scripts/hovsg-demo.sh), [GUI](../scripts/hovsg-demo.py). Нужны `full_pcd.ply`, `mask_feats.pt` и непрерывный ряд `objects/pcd_0.ply`, `pcd_1.ply`, …; viewer проверяет соответствие IDs/features и не читает большой `full_feats.pt`.

## Ограничения и ошибки

Первый расширенный build завершился CUDA OOM: нормализация dense pixel features запросила 3.11 GiB; часть памяти была зарезервирована, но не использовалась. В build wrapper добавлен `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`, как предложено самим PyTorch. Драйверы, веса и вычисления upstream не менялись. При нехватке VRAM закройте свои другие GPU-демо перед построением; одновременно строить карту и открывать второй ViT-H viewer не требуется.

20 кадров покрывают больше комнаты, чем исходные три, но карта остаётся разреженной; сегменты могут перекрываться, дробиться и включать фон. ID не является подписанным GT-классом. Подсветка результата не доказывает правильность распознавания. Semantic GT и mIoU здесь отсутствуют.

## Фактический результат

2026-10-09: расширенная карта построена exit 0, **399 663 точки и 156 сегментов** с 1024-D embeddings. Время 308.66 с, max RSS 12 941 944 KiB. После включения expandable allocator повторного OOM не было.

GUI проверен на X11/OpenGL: RGB, Instances, Similarity, Selected object, запросы `sofa`/`pillow`/`lamp`, выбор второго результата, отключение отсечения потолка, reset camera, screenshots и закрытие окна. [Скриншоты, JSON и конфиги](../results/hovsg/visual-demo/README.md). Поиск не измеряет semantic accuracy.
