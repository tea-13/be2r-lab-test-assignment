# План подготовки исследовательского репозитория

Четыре независимых Git submodules, минимальная общая инфраструктура, проверяемые инструкции, как минимум один практически проверенный сценарий для **DualMap** и **OneMap**, краткие обзоры всех четырёх методов. Полный SLAM/ROS и совместная интеграция методов не требуются.
